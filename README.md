One-line roast of a smart home gadget for the make.fun bounty "Roast the Smart Fridge: One Line, Best Laugh Wins".

## The line

> My smart doorbell filmed a guy stealing my Amazon package in 4K and sent me the clip so I could grieve in high definition.

122 characters — the doorbell films the theft in 4K but stops nothing, so the 4K selling point becomes a way to mourn in high definition.

## Run it

```sh
npx tsx main.ts
```

`main.ts` writes the line + trailing newline to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), deterministically. It guards the sealed gate: the entry must be UTF-8 text of 1–160 characters, not only whitespace, with no control characters and no leading/trailing whitespace — anything else exits non-zero and writes nothing.
